# clawed v1 Implementation Plan

> **For agentic workers:** Execute task by task with superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the clawed dynamic island: hook binary, backend (IPC, sessions, meters, approvals, tray, installer, autostart), and Svelte island UI.

**Architecture:** `clawed-hook` (sync std binary) forwards stripped hook events over a local socket to the Tauri backend, which keeps a session store and pushes snapshots to a Svelte island window. Approvals hold the socket open until the UI answers.

**Tech Stack:** Rust 1.98, Tauri 2.12, tauri-plugin-autostart 2.6, tauri-plugin-single-instance 2.5, interprocess 2.4, notify 8.2, sysinfo 0.39, tokio 1, serde_json, Svelte 5, Vite 8.

**Spec:** `docs/specs/2026-09-30-clawed-v1-design.md`

## Global Constraints

- Hook must exit 0 with empty stdout whenever the app is unreachable or anything fails.
- `Write`/`Edit`/`MultiEdit`/`NotebookEdit` content fields are never sent over IPC.
- Protocol messages carry `v: 1`; unknown versions are dropped.
- No Anthropic/Claude brand assets, no logo, no sounds. All colors and sizes in `ui/src/theme.css`.
- No timers or animation loops in the UI while collapsed.
- Release profile: `opt-level="s"`, `lto=true`, `codegen-units=1`, `panic="abort"`, `strip=true`.
- Launch at login and low memory mode default on, both toggled from the tray menu.
- Approval timeout 60 s in hook, 65 s `timeout` in settings.

**Files:** `Cargo.toml`, `.gitignore`, `crates/proto/{Cargo.toml,src/lib.rs,src/strip.rs,src/pipe.rs}`

**Produces:**

- `fn socket_name() -> String` (per-user)

Tests (`crates/proto/src/strip.rs`):

- `bash_command_truncated`: 500-char command gives 200-char summary ending in `…`.
- `todowrite_parsed`: todos extracted with status.
- `task_update_parsed`: `TaskUpdate {taskId, status}` gives `TaskDelta`.
- `missing_session_id_is_none`.
- `statusline_rate_limits_parsed`.

### Task 2: `clawed-hook` binary

**Files:** `crates/hook/{Cargo.toml,src/main.rs,src/ppid.rs,tests/hook.rs}`

**Consumes:** proto. **Produces:** binary `clawed-hook` (event mode, reads stdin) and `clawed-hook statusline`. Env `CLAWED_SOCKET` overrides the socket name (tests only).

Behavior: read stdin up to 4 MB; parse; `PermissionRequest` sends `Approval`, waits 60 s (`CLAWED_APPROVAL_TIMEOUT_MS` override) for `Decision`, prints decision JSON; everything else sends `Event` and exits. Statusline mode prints `model · ctx N% · 5h N% · 7d N%`.

Tests (`tests/hook.rs`, spawn the built binary with `env!("CARGO_BIN_EXE_clawed-hook")`):
- `app_absent_exits_zero_fast`: < 500 ms, exit 0, empty stdout.
- `malformed_stdin_exits_zero`.
- `event_forwarded`: fake server receives `HookMsg::Event` with kind `PreToolUse`.
- `approval_allow_prints_decision`, `approval_deny_prints_decision`.
- `approval_timeout_prints_nothing` (timeout 300 ms).
- `approval_release_prints_nothing`.
- `statusline_prints_line_without_app`.

- [ ] Tests fail, implement, pass: `cargo test -p clawed-hook`
- [ ] Commit `feat(hook): clawed-hook binary`
