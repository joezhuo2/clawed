# Fixtures

Recorded or synthetic Claude Code hook payloads, one JSON object per line:

```json
{"ts": 1790000000000, "payload": { ...raw hook stdin or status line JSON... }}
```

- `sample-session.jsonl` is synthetic, generated by `make_sample.py` from the documented payload shapes.
- To capture real payloads, add `--capture <abs path>/fixtures/captured-<name>.jsonl` to the hook command's `args`. Captured files are git-ignored because they can contain prompts and file paths.

Replay into a running app:

```bash
cargo run -p islet-replay -- fixtures/sample-session.jsonl --speed 2
```
